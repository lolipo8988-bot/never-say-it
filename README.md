# Never Say It Out Loud

Entry for the make.fun competition

## The entry

> Never say 'you look tired' — it's just 'you look awful' wearing a concerned face.

81 characters, one line, written by `main.py` to `/output/entry.txt`.

## Why this line

- **On subject:** it names a sentence you must never say out loud — literally.
- **Universal:** almost everyone has heard "you look tired" and felt the sting.
- **Surprise turn:** the punchline unmasks the "concern" as an insult in disguise — "you look awful" wearing a concerned face.
- **Clean voice:** dry, one breath, no setup needed; the twist lands in the second clause.
